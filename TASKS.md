# TASKS — pi-eval-kernels

Pi extension that reproduces the `eval` tool of oh-my-pi: persistent Python kernel, persistent Bun worker, loopback bridge for `tool.*` re-entry.

References:

- oh-my-pi at `can1357/oh-my-pi` (default branch, cloned 2026-10-02). Paths below are relative to `packages/`.
- Pi at `earendil-works/pi` tag `v0.99.2` (installed version: `pi --version` → `0.99.2`). Paths below are relative to `packages/coding-agent/`.
